## 5. Ketentuan teknis website

Pastikan project tetap memuat seluruh fitur yang diwajibkan:
- Fetch API DummyJSON Products menggunakan async/await.
- Pemeriksaan `response.ok`, pemrosesan JSON, dan try...catch.
- Rendering data asli API ke DOM.
- Analisis data minimal dua hasil yang dihitung menggunakan JavaScript.
- Favorit menggunakan localStorage.
- Catatan dengan validasi minimal 30 karakter.
- Light/Dark Mode dan penyimpanan preferensi tema.
- Tombol Retry ketika Fetch gagal.
- Waktu terakhir data berhasil dimuat.
- Loading, success, dan error state.
- HTML semantik dan aksesibilitas dasar.
- CSS responsif untuk desktop, tablet, dan ponsel.
- README lengkap dan AI Usage Log.

Fitur tambahan seperti pencarian, pengurutan, filter kategori, serta perbaikan tipografi harus tetap berfungsi jika sudah tersedia.

Gunakan data API secara jujur. Jangan mengarang harga, kategori, gambar, statistik, atau informasi lain yang diklaim berasal dari API.

Jika harga dikonversi ke Rupiah, jelaskan sumber kurs dan sifat konversinya. Bedakan harga asli API dari estimasi Rupiah.
